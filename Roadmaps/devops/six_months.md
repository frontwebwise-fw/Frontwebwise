# **6-Month DevOps Learning Roadmap**

This roadmap is designed for individuals who want to learn DevOps systematically over 6 months. Each month focuses on specific skills with links to resources and video tutorials for in-depth understanding.

---

## **Month 1: Linux Fundamentals**

### Week 1
- **Day 1**: Introduction to Linux, basic commands (`ls`, `cd`, `pwd`, `cp`, `mv`, `rm`).  
  - [Linux Commands for Beginners - YouTube](https://www.youtube.com/watch?v=gd7BXuUQ91w)
- **Day 2**: Practice Linux commands with real-world scenarios.
- **Day 3**: File system hierarchy overview.  
  - [Linux File Permissions - YouTube](https://www.youtube.com/watch?v=LnKoncbQBsM)
- **Day 4**: Explore file permissions with `chmod` and `chown`.

### Week 2
- **Day 5**: User management (`adduser`, `usermod`) and process management (`ps`, `top`, `kill`).  
  - [User and Process Management - YouTube](https://www.youtube.com/watch?v=LfC6pv8VISk)
- **Day 6**: Practice managing users and processes on a Linux VM.
- **Day 7**: Package management (`apt`, `yum`) and basic networking commands (`ping`, `curl`, `netstat`).  
  - [Linux Networking Basics - YouTube](https://www.youtube.com/watch?v=fHgk7aDGn_4)
- **Day 8**: Practice installing packages and using networking tools.

---

## **Month 2: Bash Scripting and Git**

### Week 3
- **Day 9**: Shell scripting basics: variables, conditions, loops.  
  - [Shell Scripting Tutorial - YouTube](https://youtube.com/playlist?list=PLS1QulWo1RIYmaxcEqw5JhK3b-6rgdWO_)
- **Day 10**: Write simple scripts for automation tasks.
- **Day 11**: Explore advanced Bash scripting features (functions, case statements).  
  - [Bash Scripting Crash Course - YouTube](https://www.youtube.com/watch?v=tK9Oc6AEnR4)
- **Day 12**: Write and debug scripts for file manipulation.

### Week 4
- **Day 13**: Git introduction: repositories, `clone`, `add`, `commit`, `push`, `pull`.  
  - [Git for Beginners - YouTube](https://www.youtube.com/watch?v=RGOj5yH7evk&t=78s)
- **Day 14**: Practice basic Git workflows.
- **Day 15**: Branching and merging strategies in Git.  
  - [Git Branching Explained - YouTube](https://www.youtube.com/watch?v=e2IbNHi4uCI&t=87s)
- **Day 16**: Practice with real-world branching scenarios.

## **Month 3: Programming (Python) Basics**

### Week 5
- **Day 17**: Python setup, basic syntax, variables, and data types.  
  - [Python Basics - YouTube](https://www.youtube.com/watch?v=kqtD5dpn9C8)
- **Day 18**: Practice working with Python data types.
- **Day 19**: Conditional statements and loops in Python.  
  - [Python Loops and Conditions - YouTube](https://www.youtube.com/watch?v=94UHCEmprCY)
- **Day 20**: Write simple Python programs with conditions and loops.

### Week 6
- **Day 21**: Functions and modules in Python.  
  - [Python Functions Tutorial - YouTube](https://www.youtube.com/watch?v=u-OmVr_fT4s)
- **Day 22**: Practice creating and using functions.
- **Day 23**: File handling and exception management in Python.  
  - [File Handling in Python - YouTube](https://www.youtube.com/watch?v=Uh2ebFW8OYM)
- **Day 24**: Write scripts to parse and process logs.

## **Month 4: Networking Basics and Docker**

### Week 7
- **Day 25**: Understand protocols (TCP/IP, HTTP, FTP, DNS).  
  - [Networking Basics - YouTube](https://www.youtube.com/watch?v=E5bSumTAHZE)
- **Day 26**: Study IP addresses and subnetting basics.  
  - [Subnetting Simplified - YouTube](https://youtube.com/playlist?list=PLIhvC56v63IKrRHh3gvZZBAGvsvOhwrRF&si=ehhXiX4Q1hI_hqY2)
- **Day 27**: Practice using tools like `nslookup` and `dig`.  
  - [DNS Basics - YouTube](https://www.youtube.com/watch?v=NiQTs9DbtW4&t=106s)
- **Day 28**: Explore firewalls, SSH, and secure connections.  
  - [SSH and Security Basics - YouTube](https://www.youtube.com/watch?v=lRMAJwMQ0Vc)

### Week 8
- **Day 29**: Introduction to Docker: installation and configuration.  
  - [Docker Introduction - YouTube](https://youtube.com/playlist?list=PLhW3qG5bs-L99pQsZ74f-LC-tOEsBp2rK&si=PhCEcy7mZp4cFAMF)
- **Day 30**: Work with Docker images and containers.  
  - [Docker Containers Explained - YouTube](https://www.youtube.com/watch?v=A0g7I4A6GN4)
- **Day 31**: Build and run custom Docker images.  
  - [Building Docker Images - YouTube](https://www.youtube.com/watch?v=C-bX86AgyiA)
- **Day 32**: Practice creating Dockerized applications.

## **Month 5: Infrastructure as Code and Configuration Management**

### Week 9
- **Day 33**: Introduction to Terraform, installation, and basics.  
  - [Terraform Introduction - YouTube](https://www.youtube.com/watch?v=SLB_c_ayRMo)
- **Day 34**: Create and manage resources using Terraform.  
  - [Terraform for Beginners - YouTube](https://www.youtube.com/watch?v=SLB_c_ayRMo)
- **Day 35**: Explore Terraform variables and state management.  
  - [Terraform State Management - YouTube](https://www.youtube.com/watch?v=yhLrH0Q-kq4)
- **Day 36**: Practice with Terraform workspaces and backends.

### Week 10
- **Day 37**: Introduction to Ansible: setup, inventory, and playbooks.  
  - [Ansible Basics - YouTube](https://www.youtube.com/watch?v=1id6ERvfozo&t=26s)
- **Day 38**: Write playbooks for software installation.  
  - [Writing Playbooks - YouTube](https://www.youtube.com/watch?v=BeYUQaFS-vg)
- **Day 39**: Manage secrets and variables in Ansible.  
  - [Ansible Secrets Management - YouTube](https://www.youtube.com/watch?v=BAgQjxBLHis)
- **Day 40**: Automate server setup with Ansible.

## **Month 6: Kubernetes and Capstone Project**

### Week 11
- **Day 41**: Kubernetes basics: installation and architecture.  
  - [Kubernetes Basics - YouTube](https://www.youtube.com/watch?v=s_o8dwzRlu4&t=104s)
- **Day 42**: Manage pods, deployments, and services.  
  - [Pods in Kubernetes - YouTube](https://www.youtube.com/watch?v=5cNrTU6o3Fw)
- **Day 43**: Explore Kubernetes networking.  
  - [Networking in Kubernetes - YouTube](https://www.youtube.com/watch?v=EkAzMGldC5M)
- **Day 44**: Practice deploying an app on Kubernetes.

### Week 12
- **Day 45-46**: Use Helm for managing Kubernetes applications.  
  - [Helm Basics - YouTube](https://www.youtube.com/watch?v=-ykwb1d0DXU&t=37s)
- **Day 47-48**: **Capstone Project**: Create a CI/CD pipeline with Docker, Kubernetes, Terraform, and Ansible.
- **Day 49-50**: Test, document, and present your project.
