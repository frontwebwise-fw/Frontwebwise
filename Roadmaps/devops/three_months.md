# DevOps Roadmap in 3 Months

This roadmap provides a structured day-wise plan to learn DevOps in 3 months (12 weeks). Each week consists of 5 active learning days and 2 days for review or rest. Resources, including video links, are provided for each topic.

---

## Week 1: Linux Fundamentals

- **Day 1**: Introduction to Linux, basic commands (ls, cd, pwd, cp, mv, rm).  
  - [Linux Commands for Beginners - English](https://www.youtube.com/watch?v=gd7BXuUQ91w)
- **Day 2**: File system hierarchy, permissions (chmod, chown).  
  - [Linux File Permissions - English](https://www.youtube.com/watch?v=LnKoncbQBsM)
- **Day 3**: User management (adduser, usermod), process management (ps, top, kill).  
  - [User and Process Management - English](https://www.youtube.com/watch?v=LfC6pv8VISk)
- **Day 4**: Package management (apt/yum), basic networking commands (ping, curl, netstat).  
  - [Linux Networking Basics - English](https://www.youtube.com/watch?v=fHgk7aDGn_4)
- **Day 5**: Shell scripting basics (variables, conditions, loops).  
  - [Shell Scripting Tutorial - English](https://youtube.com/playlist?list=PLS1QulWo1RIYmaxcEqw5JhK3b-6rgdWO_&si=IYonHLt3XLSF5pms)
  - [Shell Scripting Tutorial - Hindi](https://youtube.com/playlist?list=PL0tP8lerTbX3MeIyMxGW2sLhWnPdn_xhd&si=SR3vsD088dlwf0W1)

## Week 12: Capstone Project

- **Day 56-57**: Plan your project: CI/CD pipeline with containerized apps.
- **Day 58-59**: Implement the project: Use Terraform, Ansible, Docker, and Kubernetes.
- **Day 60**: Test, document, and present your project.

---

This roadmap will guide you to becoming proficient in DevOps in just three months. Ensure you practice hands-on regularly to solidify your understanding.
